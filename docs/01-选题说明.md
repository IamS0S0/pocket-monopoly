# 选题说明：口袋大富翁

## 项目定位

面向同学与轻度桌游玩家的本地轮流操作 3D 网页游戏。用户打开浏览器即可与朋友或 AI 进行短局对战，无需安装专用客户端。选题属于参考任务书中的游戏 / 自主选题方向。

## NABCD 分析

| 维度 | 分析 |
| --- | --- |
| N：需求 | 聚会与课间需要上手快、可控制时长、单机即可开展的轻度多人游戏。 |
| A：方法 | 用 Three.js 绘制卡通地图，以纯 JavaScript 规则引擎处理回合、资产和事件，提供 AI 补位与回合上限。 |
| B：收益 | 免后端、低使用门槛；缩短演示时间；规则与画面分离，便于测试和答辩。 |
| C：竞争 | 传统实体棋盘准备成本较高；大型数字桌游更复杂。本项目聚焦轻量浏览器体验，不以完整复刻商业规则为目标。 |
| D：推广 | 通过 GitHub Pages 发布，提供链接或二维码邀请同学试玩，并保留真实反馈。 |

## 课程要求核对

信息来源：项目根目录 `要求.txt` 与《软件工程》项目任务书 DOCX。要求文件说明任务书仅供参考，最新课堂要求优先。

- 必须展示真实可运行软件，视频仅辅助。
- 实验报告包括选题、需求分析、设计文档、测试报告。
- 代码托管到 GitHub，保留若干提交和更改记录，每名成员应有真实贡献。
- 参考任务书要求不少于 10 次有实际修改的提交、阶段文档、用户反馈；最终需要互联网试玩入口。
- 答辩重点：某功能对应代码、程序架构、技术栈和测试方法。
- 小组信息、分工、学号和用户反馈待真实信息补充，不编造。
